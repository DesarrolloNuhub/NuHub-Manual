Matriz LOIN: ¿cada elemento tiene la información que pide el proyecto?

La Matriz LOIN revisa, elemento por elemento, si tiene la información que exige el proyecto (nivel de necesidad de información, ISO 7817-1). Te dice qué cumple, qué falta y en qué parámetro, con imágenes de cada tipo.

Dónde encaja

Complementa al Auditor: el Auditor mira reglas del modelo; LOIN mira los datos de cada elemento.

Paso a paso

El detalle de cada paso del mapa: qué botón pulsar y qué pasa.

Abre el modelo y LOIN

Pulsa LOIN. Lee las categorías modeladas, igual que Cantidades.

Define el contexto

En Contexto del requerimiento (ISO 7817-1) escribe el Propósito, el Hito y el Actor. Salen en los informes.

Elige los parámetros LOIN

Parámetros LOIN: hasta 15 por categoría. Los del Resumen aplican a todas. Guarda todo en Configuraciones (máx. 5).

Ajusta las reglas

En Reglas defines los comodines que cuentan como vacío (por ejemplo «N/A» o «-»), si se exige «IFC Export As» y reglas de valor por parámetro.

Genera las imágenes

Generar imágenes crea un isométrico por Type Name, con colores, para que la matriz muestre cómo es cada tipo.

Revisa el tablero

El tablero muestra instancias evaluadas, cuántas cumplen (tienen toda la información), el cumplimiento promedio, qué categoría falla más y qué parámetro falta más.

Completa lo que falta

La matriz marca Falta o Valor no válido en cada celda. Completa los datos en el modelo (o con Editar Información) y pulsa Volver a leer.

Exporta la matriz

Exportar… a Excel o PDF A3, con todos los elementos, solo los completos o solo los que tienen faltantes. También PDF de lo que cumple y PDF de lo que falta.

Ejemplos de uso

Situaciones reales de un proyecto y cómo se resuelven con Matriz LOIN.

Verificar información para el contratista

Coordinador BIM · entrega para construcción

  1. Define el contexto: propósito «Construcción», hito «Entrega 3».
  2. Elige marca, material y código de presupuesto para puertas y ventanas.
  3. Revisa el tablero: 64 % de cumplimiento.
  4. Exporta el PDF de lo que falta y lo envía al modelador.

Resultado: el modelador sabe qué elementos y qué parámetros completar.

Matriz para el cliente

BIM manager · anexo del BEP

  1. Genera las imágenes isométricas.
  2. Exporta la matriz completa a Excel.

Resultado: un anexo con cada Type Name, su imagen y la información que tiene.

Ignorar valores de relleno

Auditor de información · modelos de terceros

  1. En Reglas agrega los comodines «xx», «pendiente» y «-».
  2. Vuelve a leer el modelo.

Resultado: los parámetros llenos con relleno cuentan como vacíos y el cumplimiento es real.

Cómo se lee la matriz

Cada fila es un elemento; cada columna, un dato exigido.

Lo que vesSignifica
CumpleEl elemento tiene todos los datos exigidos.
FaltaEl parámetro está vacío o tiene un comodín.
Valor no válidoTiene un valor, pero no cumple la regla de ese parámetro.
Cumplimiento promedioDatos llenos divididos entre datos exigidos.

Preguntas frecuentes

¿Qué gasta un uso?

Cada exportación a Excel o PDF. Revisar el tablero, generar imágenes y volver a leer no gasta usos.

¿Qué es un comodín?

Un texto que cuenta como vacío aunque el parámetro esté lleno, como «N/A» o «-». Se configuran en Reglas.

¿Las imágenes cambian el modelo?

Para tipos de sistema (muros, pisos, cubiertas) puede modelar una muestra temporal y la borra al terminar.

¿Qué es ISO 7817-1?

La norma del nivel de necesidad de información: qué información pide cada actor, en cada hito y para qué propósito.
